Ключевые анимации и взаимодействия
Welcome → Menu: Весь экран slide-up (translateY 0 → -100%) за 0.5s ease-out. Новый экран появляется снизу.
Барабан (drum): Вертикальный свайп. CSS transform: scale + rotateX + blur + opacity. Активная карточка = scale(1) + 0 blur. Соседние = scale(.82) + blur(1px). Дальние = scale(.7) + blur(2px). Бесконечный цикл.
Liquid glass: На активных элементах — gradient overlay (rgba(255,255,255,.12) → transparent → rgba(255,255,255,.04)). Имитирует отражение света на стекле.
Добавление в корзину: Иконка товара анимируется от карточки → к иконке корзины (bezier path). Cart badge делает bounce. Корзина внизу обновляется с fade-in нового элемента.
Открытие товара: Карточка "вырастает" из своей позиции (scale 0.8 → 1, opacity 0 → 1, translateY 50px → 0). Закрытие — обратная анимация.
Комбо сборка: При нажатии «Добавить комбо» все 4 элемента собираются в центр (animate translateX/Y), merge в одну карточку, которая "падает" вниз в корзину с bounce.
Модификаторы: При тапе — scale(1.1) → scale(1) + glow pulse. Горизонтальный свайп с инерцией (touch-scroll с deceleration).
Корзина-трей: Drag handle для раскрытия/сворачивания (свайп ↕). Свернутая = мини-превью. Развёрнутая = полный список с допродажами.
